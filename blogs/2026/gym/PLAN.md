# 健身计划生成器 · 计划与进度

## 目标

用户输入当下的条件（器械、室内/室外、空间、是否怕吵、有没有运动鞋、时长、强度、练完能不能洗澡、目标、需要避开的部位），
系统自动组合出一节**单次训练**（热身 → 主训练 → 放松），然后**像 Keep 一样全程跟练**：
打开就跟着做，语音播报每个动作、自动计时、自动切换，不需要暂停也不需要做任何选择。

与 Keep 的区别：Keep 是固定课程套餐让用户挑；这里是**按条件定制 + 智能组合**，每次为当下量身生成。
生成的训练可以**保存为模板**，下次直接开练，或用同样条件"换一批"动作。

路线：先做电脑本地网页版 → 部署成网页/PWA 在手机上用 → 真有需要再用 Capacitor 打包成 App（上架成本高，暂不考虑）。

当前能做的事：

- 选条件 → 生成训练 → 预览（每个动作的组数/次数/时长/休息/要点）
- "换一批动作"：同条件、新随机种子
- 保存为模板（默认名如"室内-瑜伽垫+哑铃-30分钟-中强度-不出汗"）、模板列表一键开练/换一批/删除
- 跟练：准备倒计时 → 动作 → 休息（预告下一个）→ …；中文语音播报、最后 3 秒提示音、计次动作显示"第 n / N 次"、单侧动作自动拆成左右两侧、屏幕常亮；有暂停/跳过/结束按钮备用

生成规则要点：

- 不能洗澡 → 出汗等级上限 2，主训练用慢节奏常规组；能洗澡时出汗上限随强度放开
- 没鞋 → 去掉跑跳；需要安静 → 去掉跳跃；空间小 → 去掉需要移动的动作；身体限制 → 去掉对该部位压力大的动作
- 力量目标 → 常规组（组间休息按强度 60/75/90 秒，不能洗澡时固定 60 秒）；减脂/综合 → 计时循环（做/休 30/30、40/20、45/15，轮间休息 60 秒）；柔韧 → 拉伸流（动作间 5 秒衔接）
- 休息档位：以上主训练休息统一 −15 / 0 / +15 秒，最少 10 秒；热身、放松、拉伸流的衔接不变
- 时长：1800 种条件组合（含三档休息）测试中误差都在 15% 以内

测试：30 个（动作库完整性、过滤、生成、时间线、存储、界面全流程），`npm test` 全部通过。

## 已知问题 / 限制

- 2026-10-10 已在 Windows 浏览器里打开 `npm run dev`（http://localhost:5173/）确认能用；完整跟练体验和调参反馈待收集。WSL2 是 NAT 网络，手机暂时访问不到开发服务器
- 语音依赖系统的中文语音包（Windows/macOS/手机一般自带）；没有中文语音时只会静默，计时不受影响
- 模板命名用的是浏览器 `prompt` 弹窗，比较简陋
- 动作库的标签（出汗、强度、每次耗时等）是我按常识填的，需要你审核
- 数据只存在当前浏览器里，换浏览器/设备看不到

5. **动作视频**：每个动作一段"单次动作循环"短视频，跟练时按时长循环播放（视频时长天然等于训练时长）；播放器里已留好位置
6. **PWA**：可添加到手机桌面、离线可用
7. **训练记录**：完成打卡、历史
