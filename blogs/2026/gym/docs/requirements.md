# 需求文档

## 定位

根据用户当下的条件（器械、场地、时长、强度、能否洗澡等），自动生成一节**单次训练**；
生成的训练可以**保存为模板**，下次直接调用或用相同条件重新生成。

**与 Keep 等应用的区别**：Keep 提供固定的课程套餐让用户挑选；本应用根据用户的条件**定制 + 智能组合**，
每次生成一套为当下量身搭配的课程，同样可以完全跟着做。

第一阶段为**电脑本地网页版**：`npm run dev` 后在浏览器中使用，数据保存在浏览器本地，无需服务器和账号。
以后可部署为 PWA 在手机上使用，再视需要用 Capacitor 打包成 App。

## 用户输入（训练条件）

| 类别 | 条目 | 对生成的影响 |
|---|---|---|
| 器械 | 哑铃、杠铃、壶铃、弹力带、瑜伽垫、单杠、跳绳、椅子/凳子（徒手始终可用） | 硬性过滤：缺器械的动作不出现 |
| 场地 | 室内 / 室外 | 过滤只适合某种场地的动作 |
| 空间 | 小（原地）/ 大（可移动、跑动） | 空间小时排除需要移动的动作 |
| 安静 | 是否需要避免噪音（如楼上楼下） | 排除跳跃等高噪音动作 |
| 运动鞋 | 有 / 无 | 无鞋时排除跑跳、冲击类动作 |
| 时长 | 15 / 20 / 30 / 45 / 60 分钟 | 决定动作数量、组数、轮数 |
| 强度 | 低 / 中 / 高 | 决定动作强度、休息时间、训练形式 |
| 练后能否洗澡 | 能 / 不能 | 不能时限制出汗等级（≤2），避免高出汗动作 |
| 休息 | 短一些 / 默认 / 长一些 | 主训练休息比默认少或多 15 秒（最少 10 秒） |
| 目标 | 综合、减脂、力量、柔韧放松 | 决定主训练的形式与动作类型比例 |
| 身体限制（可选） | 膝、腰、肩、手腕 | 排除对该部位压力大的动作 |

## 生成的训练结构

```
热身    约 15% 时长   低强度、动态活动
主训练  约 70% 时长   按目标与强度：力量组 / 循环 / 间歇
放松    约 15% 时长   静态拉伸、呼吸
```

- 力量目标：常规组（组 × 次，组间休息）
- 减脂 / 高强度：循环或间歇（做 N 秒、休 M 秒，若干轮）
- 不能洗澡：只选出汗等级低的动作，休息更长，节奏更慢
- 柔韧放松：以拓展、瑜伽类动作为主

## 保存与调用

- 生成结果可保存为模板，保存时命名（如"办公室-徒手-15分钟-不出汗"）
- 模板包含**条件**和**生成结果**
- 调用方式：
  1. 直接调用：按原样再练一次
  2. 重新生成：沿用条件，换一批动作
- 模板可删除；记录创建时间和最近使用时间

## 跟练模式（核心体验）

用户制定好计划后，打开跟练，**全程跟着做即可，不需要暂停、不需要做任何选择**：

- 按时间线自动播放：语音播报"第一个动作：卷腹"→ 准备倒计时 → 开始 → 计时/计次 → 休息（预告下一个动作）→ 下一个
- 每个动作的时长都是确定的：计时动作直接用秒数；计次动作 = 次数 × 每次耗时（`secPerRep`，含左右两侧）
- 指导内容的时长必须与训练时长一致，不能"偷懒"缩短
- 视频：每个动作准备一段"单次动作循环"短视频，跟练时按该动作时长循环播放，
  因此视频时长天然等于训练时长；MVP 阶段先用 计时器 + 中文语音播报 + 动作要点文字
- 动作指导用 3D 简洁人偶实时动画：每个动作一个循环（计次动作 = 一次）的关键帧，跟练时按计时播放，
  每做完一次换一个视角（正面 / 侧面 / 全身；躺、撑的动作先看侧面），太快的动作每几次换一次（每个视角至少 2.5 秒）；
  首尾姿态相同，换视角时动作连贯。休息时预演下一个动作
- 以后如有 AI 视频片段，优先播放视频（规范见 `docs/video-guide.md`）
- 用户可选视频教练（女 / 男）和语音播报（女声 / 男声），记住选择；
  本机没有所选性别的中文语音时，用其他中文语音并调整音调代替，并提示用户
- 仍提供暂停/跳过按钮以备意外，但正常流程无需操作

## 人体肌肉图

- 每个动作配一张人体肌肉图（正面 + 背面），只画人物轮廓和用到的肌肉：主要橙色、次要浅橙色，没用到的不画，下方列出肌肉名称；拉伸类动作写"拉伸"
- 计划预览里点开动作可看；跟练时显示当前动作（休息时显示下一个动作）
- 肌肉分 16 块：胸肌、三角肌、斜方肌、背阔肌、下背、肱二头肌、肱三头肌、前臂、腹直肌、腹斜肌、髋屈肌、臀肌、股四头肌、腘绳肌、大腿内侧、小腿

## 训练报告与历史

- 跟练做完，或中途结束但已练满 1 分钟，自动记录并显示训练报告；不足 1 分钟不记录
- 报告：实际训练时长（跳过的部分不算）、完成度、完成组数、动作时间（不含休息）、
  估算热量（按动作强度的 MET × 体重，需填一次体重，明确标"估算"）、练到的部位、每个动作完成的组数和次数
- 最近 7 天每天的训练分钟数、最近 8 周（周一开始）每周分钟数、近 7 天次数/时长/练了几天、连续打卡天数
- 首页"训练记录"展示同样的趋势和最近 10 条记录，点开可看当次报告
- 记录只存在当前浏览器里

## MVP 范围

1. 填写条件 → 生成一次训练
2. 查看训练详情（动作、组数、次数/时长、休息、要点）
3. 保存为模板、模板列表、调用、删除
4. 用相同条件重新生成
5. 跟练模式：计时器 + 语音播报，自动连续播放整节课

- 多周计划、渐进超负荷
