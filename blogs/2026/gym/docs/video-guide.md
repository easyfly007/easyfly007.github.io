# 动作视频：AI 生成规范

## 播放方式

每个动作、每个视角只存**一次动作**的短片段。跟练时按次拼接，每做完一次换一个视角：

```
第 1 次 正面 → 第 2 次 侧面 → 第 3 次 全身 → 第 4 次 正面 → …… 直到做完
```

例：深蹲 20 次 = 正面片段播 7 次 + 侧面 7 次 + 全身 6 次，交替拼接。后台只需存 3 个片段。

- 计次动作：一个片段 = 一次动作。播放器会把片段缩放到动作库里的每次时长（`secPerRep`，如深蹲 3 秒），
  所以画面、计时、"第 n 次"计数始终对齐，整节课时长不变
- 计时动作（平板支撑、开合跳等）：一个片段 = 5 秒，每 5 秒换一个视角
- 单侧动作：左右各一套片段，跟练左侧时放左侧片段
- 两位教练（女 / 男）各一套片段，用户在首页"教练与语音"里选择；所选教练还没有某个动作时，暂用另一位的

## 硬性要求：首尾姿态一致

不同视角的片段要能无缝接上，看起来是**同一个人连续做了 20 次**：

1. **每个片段都从同一个起始姿态开始，并回到这个姿态结束**（深蹲：站直、双臂自然下垂或前平举，按统一规定）
2. **同一动作的三个视角，起始姿态完全相同**，只是机位不同
3. 片段里**只做一次**，不能多也不能少；开头和结尾不要有多余的停顿或准备动作

做法（推荐用支持"首帧 + 尾帧"的图生视频功能）：

1. 先做**角色参考图**：女、男教练各一张，各自固定服装和发型，背景相同（浅色室内）
2. 每个动作出 3 张**起始姿态图**（正面 / 侧面 / 全身视角各一张，同一姿态）
3. 每个片段用这张图**同时作为首帧和尾帧**生成，强制首尾一致
4. 文字提示词用 `docs/video-clips.csv` 里的（由 `scripts/video-list.ts` 从动作库自动生成）

## 视角

| 视角 | 文件名 | 机位 |
|---|---|---|
| 正面 | `front` | 正前方，腰部高度平视，全身入镜 |
| 侧面 | `side` | 正侧面（人物左侧对镜头），腰部高度平视，全身入镜 |
| 全身 | `full` | 右前方 45°、略高于头部向下俯拍，全身和地面入镜 |

固定机位：不移动、不变焦、不剪辑；无字幕、水印、音乐。

## 文件格式与存放

- `src/videos/<教练 female|male>/<动作 id>/<视角>.mp4`，单侧动作为 `<视角>-left.mp4` / `<视角>-right.mp4`
  （完整路径见 `docs/video-clips.csv` 第一列）
- 放进去就会被自动收录，不需要改代码；缺某个视角时只在已有视角之间轮换，一个都没有时只显示文字
- MP4（H.264），16:9，720p，去掉音轨，每段尽量 < 2 MB；也接受浏览器录制的 `.webm`
- 片段长度建议 5 秒，一次动作正好占满整段。若缩放到 `secPerRep` 后看起来太快或太慢，
  应调整动作库里该动作的 `secPerRep`，不要剪片段

## 验收清单（每个片段）

- [ ] 第一帧和最后一帧姿态一致，循环播放看不出跳动
- [ ] 只做了一次，动作标准，符合动作要点（膝盖朝向、背部姿态等）
- [ ] 手、脚、器械没有变形或穿模
- [ ] 人物、服装、背景与其他片段一致
- [ ] 机位与视角定义一致，镜头没有移动

## 规模

83 个动作，其中 23 个单侧：(83 + 23) × 3 视角 = 318 个片段，女、男两位教练共 **636 个片段**。
建议先做深蹲的 3 个片段，放进去实际跟练看拼接效果，再批量生成。
